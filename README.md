# 🐍 Classic Snake Game

A nostalgic recreation of the classic Nokia Snake game, built with pure HTML, CSS, and JavaScript. Play it in your browser with both keyboard and mobile touch controls!

## 🎮 Live Demo

Play the game directly in your browser: [https://amirdorot.github.io/snake_html/](https://amirdorot.github.io/snake_html/)

## ✨ Features

- **Classic Nokia-style gameplay** - Authentic green-on-black retro theme
- **Dual control methods** - Keyboard arrows + mobile touch buttons
- **Responsive design** - Works perfectly on desktop, tablet, and mobile
- **Smooth gameplay** - Optimized speed and collision detection
- **Score tracking** - Keep track of your high scores
- **Pause/Resume** - Take a break anytime with spacebar or pause button
- **Game over handling** - Easy restart functionality

## 🎯 How to Play

### Desktop Controls
- **Arrow Keys** - Move the snake (↑↓←→)
- **Spacebar** - Pause/Resume the game

### Mobile Controls
- **Touch the arrow buttons** - Move the snake in any direction
- **Pause button** - Tap to pause/resume
- **Play Again** - Restart when game ends

### Game Rules
1. 🐍 Control the green snake to eat red food
2. 🍎 Each food eaten increases your score by 10 points
3. 📏 Snake grows longer with each food consumed
4. 💥 Avoid hitting walls or yourself
5. 🏆 Try to achieve the highest score possible!

## 🚀 Getting Started

### Option 1: Play Online
Simply visit the live demo link above - no installation required!

### Option 2: Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/amirdorot/snake_html.git
   cd snake_html
   ```

2. Open `index.html` in your web browser:
   ```bash
   open index.html
   ```

3. Start playing immediately!

## 🛠️ Technical Details

- **Pure client-side** - No server required
- **Canvas-based rendering** - Smooth 60fps gameplay
- **Mobile-optimized** - Touch-friendly controls
- **Responsive design** - Adapts to different screen sizes
- **Cross-platform** - Works on any modern browser

## 📱 Mobile Support

The game is fully optimized for mobile devices:
- Touch-friendly control buttons
- Responsive canvas sizing
- Optimized button sizes for fingers
- No keyboard required

## 🎨 Customization

The game is built with vanilla HTML, CSS, and JavaScript, making it easy to customize:
- **Colors** - Modify the CSS variables for different themes
- **Speed** - Adjust the `setTimeout` delay in the game loop
- **Grid size** - Change the `gridSize` variable
- **Scoring** - Modify the score increment value
